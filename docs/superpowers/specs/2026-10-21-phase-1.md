# Fase 1: API de comercio exterior

Decisiones aprobadas por el usuario: FastAPI, SQLAlchemy, SQLite configurable,
monolito por capas, Argon2id/JWT, transacciones atómicas, filtros SQL y páginas
1/20 con máximo 100. Sin KPIs, caché, despliegue ni nuevas funcionalidades.

Fuente: PDF local (tres páginas), schema.png y setup.py inspeccionados el 21/10/2026.
Rutas: POST /register, POST /login; GET /dimensions/paises,
/dimensions/aduanas, /dimensions/tipos-regimen; POST y GET /polizas;
GET /polizas/{id}. Todas las rutas de negocio requieren Bearer JWT.

Contrato mínimo donde el PDF no define payload: username/password JSON,
username sensible a mayúsculas, JWT HS256 de 30 minutos configurable.
Identificadores positivos, correlativo entero de 64 bits, fechas ISO y números
finitos; no se inventan límites de impuestos, importes ni tipos de cambio.
Creación requiere cabecera completa, referencias válidas y al menos un ítem.
Lectura admite NULL donde el esquema legado lo permite. Lista sin ítems;
detalle con ítems. Filtros AND por correlativo, rango inclusivo de fechas,
aduana, régimen, país y SAC (país/SAC deben coincidir en un mismo ítem).
Orden ascendente por id y metadatos total/page/page_size. Conflictos: 409;
validación: 422; no autenticado: 401; póliza inexistente: 404.

Inicialización explícita e idempotente de tablas ausentes, nunca al importar
ni al arrancar el servidor. No alterar tablas existentes ni ejecutar setup.py.
La tabla users se agrega con ese comando. Las pruebas usan SQLite temporal.
OpenAPI se exporta por CLI; no se habilitan rutas públicas de documentación.

## Inspección y limitaciones

- Base original: 26,076 pólizas; 1,710,744 ítems. quick_check=ok;
  foreign_key_check sin infracciones. CSV presente; no se volvió a importar.
- setup.py elimina la base antes de validar el CSV. NOT_NULL se interpreta
  como parte del tipo y no como restricción NOT NULL. El ETL confirma bloques
  por separado y puede dejar cargas parciales; no se modifica en esta fase.
- Fechas observadas: 1970-01-20 a 2025-05-16; no se corrigen datos sin regla.
- setup.md propone uv pip sync sin archivo: usar uv sync --locked.
- .venv original difiere del lock; usar entorno aislado y el lock actualizado.
- main tenía un merge pendiente con README en staging. Trabajo en worktree
  separado desde 211327d, rama main-phase-1-backend; no cerrar ese merge.
- Docker y logs estructurados del PDF quedan para una fase posterior, junto
  con KPIs/caché. PostgreSQL requerirá driver, migración y pruebas específicas.
